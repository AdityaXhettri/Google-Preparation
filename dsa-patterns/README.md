## Daily Practice Routine

- **Weekdays:** 1 pattern → 2-3 problems (45-60 min)
- **Saturday:** 1 random medium (timed, 25 min) — like real interview
- **Sunday:** Review week's mistakes, re-solve 1-2

## How I solve a problem

1. Read problem, restate in my own words (2 min)
2. Brute force + identify pattern (3 min)
3. Code optimal solution (15-20 min)
4. Test edge cases (5 min)
5. Write takeaway in problem file (5 min)

**Total: 25-35 min per problem**
