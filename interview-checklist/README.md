# Interview Day Checklist

> Review this 1-2 days before each interview round.

## DSA Round (45-60 min)

- [ ] Can solve medium in 25 min cold
- [ ] Can solve hard in 40 min cold
- [ ] Pattern-recognition ready (problem → template in 30 sec)
- [ ] 18 patterns reviewed (at least `../dsa-patterns/README.md`)
- [ ] Recent mistakes re-solved

## Coding Fundamentals

- [ ] HashMap/Set O(1) — reflex
- [ ] Sort with custom comparator — reflex
- [ ] BFS/DFS templates — memorized
- [ ] Big O analysis — can derive quickly
- [ ] Edge cases to always ask: empty, 1 elem, duplicates, overflow

## System Design Round (45 min)

- [ ] Read `../system-design/README.md` format
- [ ] Reviewed 3 most recent write-ups
- [ ] Can articulate trade-offs (cache vs DB, SQL vs NoSQL, sync vs async)
- [ ] Knows scale estimation (QPS, storage)

## Googleyness Round (45 min)

- [ ] All 6 stories rehearsed <2 min each
- [ ] Each story has 3+ metrics/numbers
- [ ] Can answer 4 follow-ups per story
- [ ] Reviewed `../googleyness-stories/`
- [ ] 1 story for each of: ambiguity, feedback, status quo, user first, right thing, team

## Logistics

- [ ] Resume printed (2 copies) or on second screen
- [ ] Quiet room, good lighting, water
- [ ] Stable internet (for virtual)
- [ ] Phone silenced
- [ ] 10 min buffer before interview

## Morning routine (day of)

- [ ] Light breakfast
- [ ] 5 min review of pattern cheatsheet
- [ ] 1 easy warm-up problem (just to get brain going)
- [ ] Deep breath. You're prepared.
